Genomic network analysis of specific cognitive abilities
======
Network analysis has been around for a while, especially in psychology, where its used in psychometrics to study how items and constructs relate to one another. Network analysis is useful because it takes a complex, multivariate system of different variables, and distills the most essential connections between them. They are represented using undirected graphical models where circles (called nodes) represent variables, and the lines connecting them (called edges) represent conditional dependencies. In other words, if you control for the influence of all other variables, are two variables still correlated? We can use this concept to study pleiotropy, by calculating a genetic covariance matrix and fitting an undirected network model to seperate horizontal pleiotropy (where two traits have a common genetic basis) from veritcal pleiotropy:
